Welcome to your institute CRM.

Already installed and logged in? Do not run setup again. Read UPGRADE.html to add academic operations, fee schedules and the student portal while keeping your database, config.php and storage safe.

The ready-to-install ZIP includes PHPMailer and PDF libraries. You do not need to edit PHP files or install Composer when using this package.

Start on Windows with XAMPP

  1. Extract the institute-crm folder into C:\xampp\htdocs\.
  2. Open XAMPP Control Panel. Start Apache and MySQL. Use PHP 8.2 or newer.
  3. Open http://localhost/institute-crm/public/setup.php in your browser. Do not open a PHP file directly from File Explorer.
  4. Open C:\xampp\htdocs\institute-crm\storage\setup-key.txt in Notepad. The setup page creates this private file on its first visit. Copy the key into the setup page.
  5. Follow the wizard: server checks → database → owner/institute → PHPMailer/Gmail → verify inbox → install.
Standard local XAMPP database settings:
Host: 127.0.0.1 · Port: 3306
Username: root · Password: blank by default
Database: institute_crm
Choose “Create this database if it does not exist”. Use a new, empty database; existing data is never erased.

Gmail settings

SMTP host: smtp.gmail.com · Port: 587 · Encryption: STARTTLS. Use your Gmail address for username and sender. Enable Google two-step verification and create an App Password. Enter that App Password only in the setup form—not your normal Gmail password and never in a chat.

Setup sends a code to your owner email. Enter it to verify the connection before installation. Login codes are then sent immediately through PHPMailer.

Student PDF emails

Admission/payment emails use a queue. After setup, schedule php bin/send-notifications.php --limit=25 every minute using Windows Task Scheduler or your hosting control panel. See docs/BROWSER-SETUP.md and docs/GMAIL-SETUP.md.

Moving to live hosting

Use HTTPS, serve only public/, protect private files, and use a dedicated database account. Choose Live server mode in the wizard for a fresh deployment. Existing installations must follow the upgrade instructions, not rerun setup.

Setup locks permanently after completion. The private setup key is removed. Neither this package nor the preview includes working Gmail credentials. Real SMTP/MySQL delivery must be tested on your server before using student data.

If you downloaded GitHub source instead

GitHub source does not include vendor/. Run composer install --no-dev --prefer-dist once, or use the ready-to-install ZIP. The wizard detects missing libraries and extensions and explains what to fix.
